# @liminal-hq/folio-mcp

An [MCP](https://modelcontextprotocol.io) server that lets an AI agent make, edit, check and export books in [Folio](https://github.com/liminal-hq/folio).

```sh
npx @liminal-hq/folio-mcp
```

Add it to an agent program with `npx @liminal-hq/folio-mcp install claude-code` (or `claude-desktop`, `cursor`, `vscode`, `windsurf`, `codex`, `gemini`). If Folio is running, the agent works on the books you have open, and you can undo what it does.
