# Read-aloud pacing

**Area:** Picture-book extras · **Prototype:** `Folio Picture Book.dc.html` · **Status:** artboard → merge into Folio

## What it does
Estimate how long each spread takes to read aloud and spot spreads that are too wordy.

## UI
Pacing bar per spread (seconds), word counts, target range for the age group.

## Model and engine
Words ÷ 130 wpm (adjustable); age presets.

## Jax
Jax can read it at bedtime pace.

## Done when
- Works in Easy with plain words; Expert shows the numbers.
- Undo covers every change in one step per action.
- Preflight (05) knows about it where relevant.
