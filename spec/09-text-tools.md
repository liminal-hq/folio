## Granularity (D-10)

- **Easy:** formatting applies to the **whole box**, even while typing. The first time someone tries to style a selection, a one-off toast explains that Expert mode can style single words.
- **Expert:** while typing, formatting applies to the **selection**. With no selection, or when the box is just selected, it applies to the whole box.
- Superscript, subscript and links need a selection, so they always need Expert mode plus a text selection.

## Model: runs

```ts
interface Run { t: string; b?: boolean; i?: boolean; u?: boolean; st?: boolean; sc?: boolean; sup?: boolean; sub?: boolean; c?: string; hl?: string; href?: string }
interface TextFrame { text: string; runs?: Run[]; /* box-level */ s: StyleId; font?: string; pt?: number; b?; i?; u?; st?; sc?; c?; hl?; ls?: number /*em*/;
  al?: Align; lh?: number; sa?: Pt; ind?: Inches; fi?: Inches; list?: 'bullet' | 'number'; dc?: boolean; ot?: string[] }
```

- `text` is always the plain text, kept for search, the reader preview and EPUB fallbacks. `runs` exists only when the box has mixed styles.
- Box-level properties are defaults; run properties override them. **Clear formatting** removes both.
- Paragraphs are `\n`-separated. List, indent, first-line indent, space after and drop cap are paragraph-level and apply to every paragraph in the box (v1). Per-paragraph overrides are planned for 1.1 and will be stored as `paras: [{ list, ind, … }]`.
- Rust: `Run` / `TextFrame` in `folio-model` (see `crates/folio-model`); `runs` serialise as `content.inline` (03). A `Run` so far carries `text`, `style`, `bold`, `italic`, and an optional `font` (a typeface for those words) and `colour` (`#rrggbb`) that win over the style's; layout draws each run with them and sends the colour to the canvas. A style may also name a `colour`. The ribbon's **Font** list sets a typeface for the whole of the selected text frames (`StyleOverrides.font`); it offers the bundled families, the ones the book keeps and the ones installed on the computer, and choosing an installed one keeps its files inside the book when its licence allows (D-30), so the book opens the same elsewhere. Underline, strike, small caps, super and subscript, highlight and links are still to come.
- **Selection styling (built, Expert):** with words selected in the open editor, the ribbon's Bold, Italic and Font act on just those characters through `StyleRange { frame, start, end, change }` (offsets in characters, one undo step; the run is split where the stretch begins and ends and neighbours that look alike are joined). Bold or italic turns off when the whole stretch already has it. Editing the words afterwards (`SetText`) keeps the look of the stretches that were not touched, and words typed inside a stretch take its look, so a styled frame no longer needs to be locked out of editing. While typing, the box shows plain words; the styled look appears on the page. The Home tab's **Text colour** list (ink, then eight colours that read well on paper; "Colour from style" takes it away) colours the selected words in the same way, or all of the frame's words when none are selected. **Not built:** a free colour picker, superscript, subscript and links, and the Easy-mode toast.

## Editing

- Double-click (or Enter) opens a `contentEditable` editor seeded from `runsToHtml(runs)`. Box-level styles apply to the editor itself.
- Commit (blur, Esc, clicking the page) parses the DOM back with `domToRuns` (tags B/I/U/S/SUP/SUB/A plus inline `font-weight`, `font-style`, `text-decoration`, `font-variant`, `color` and `background-color`). Adjacent equal runs are merged, and if nothing is rich the result collapses back to plain `text`.
- In the desktop app the editor is a Rust-shaped text view rather than `contentEditable` (02): a caret and a selection over the lines Rust laid out, with the keys going to an invisible input. The run model is the same.
- **The editor on the page (D-53), the default (Preferences → Editing → Edit text on the page itself, `editing.newEditor`, on; turning it off brings back the plain text box, kept as a fallback for a release, D-54):** double-clicking a text frame that holds its own words puts a caret and a selection over the frame's own lines instead of a text box, so edit mode wraps, hyphenates and justifies exactly as the page does and the frame's formatting is unchanged while typing. Keys and input methods go to an invisible text area at the caret (so an input method's candidate list opens there; the word being composed is shown underlined at the caret until it is committed). Every change is an `EditText` edit sent in one call that also lays the spread out again (`edit_text`), and keys pressed while one is in flight wait for it and take their place from its answer. Click, Shift+click, drag, double-click (a word) and triple-click (a paragraph) place and select; the arrows, Ctrl+arrows (words), Home, End, Ctrl+Home/End, Ctrl+A, Enter, Backspace, Delete and Ctrl+Backspace/Delete work as in a word processor, and the ribbon's Bold, Italic, Font and Text colour act on the selected words through `StyleRange`. With the caret alone in the words, Bold, Italic, Font and Text colour set a look for the words typed next (a pending look: pressing Bold again takes it back; moving the caret forgets it), sent with the first words typed after it as the edit's `look`. Plain-text copy, cut and paste work. Ctrl+Z and Ctrl+Y (and the ribbon and menu) undo and redo one step of the book at a time and the editor stays open: the caret goes back to where the step had it, which is the selection a replacement covered or where a stretch of typing began (the session keeps both with the step, and `restored_caret` says them after an undo or redo). Copy puts three things on the clipboard: Folio's own paragraphs of runs (`application/x-folio-text+json`), simple HTML (`<strong>`, `<em>` and a colour) for other programs and plain text; pasting what Folio copied keeps bold, italic, font and colour (`EditText` with rich paragraphs), and anything else pastes as plain words. The same editor edits a shape's words, a table cell's (Tab and Shift+Tab move between cells, and Tab out of the last one adds a row) and, for a frame in a story, the whole story: the caret starts at what the frame shows first, and the story's pages follow the words as before. In a story or a table cell the ribbon's Bold, Italic, Font and Text colour act on the selected words through `StyleText { target, from, to, change }` (places are paragraph and code point, as in an edit; the stretch may cross paragraphs and is one undo step), and Bold, Italic, Font and Text colour at a caret alone set a pending look there too. The ribbon shows the look of the words under the selection or the caret: Bold and Italic are pressed only when every selected character has them, and the Font list names a typeface only when the whole stretch shares it (D-59). The caret and a selection cross from one frame of a story to the next on the same spread: the arrow keys, Home and End, up and down (keeping the column from the frame's left edge), a click in any of the story's frames and a drag from one into another (D-60). The frames of the story on other spreads are out of reach for the caret and a drag, and a story with a turned frame on the spread keeps the caret in the frame being edited. Still to come on this editor: pasting formatted text from other programs, and selecting across spreads. Misspelt words are underlined with the squiggles the page itself draws (they come with the layout, so they are the same on the page and while editing); right-clicking one, or Shift+F10 or the Menu key with the caret in it, offers corrections, **Ignore** and **Add to dictionary**, a correction is a step of its own, and **Alt+F7** selects the next misspelt word.
- Ctrl+B/I/U work while typing and on a selected box.
- **Smart punctuation as you type (D-57, `editing.smartPunctuation`, on by default):** in the on-page editor typed and pasted plain words are set by the rules of `folio_model::smarten` as they go in (straight quotes curly, in French « » with non-breaking spaces and in German „ “ by the book's language; `--` an em dash, a spaced hyphen an en dash, `...` an ellipsis), in the same `edit_text` call (`EditRequest.smart`, answered with a `SmartNote`). Backspace straight after a conversion puts back the characters typed, as one more undo step, and the next characters are left as typed. Pasted Folio formatting, Enter, deletions and input-method compositions are not changed. The Home tab's Smart punctuation toggle, Edit → Smart punctuation as I type and Preferences → Editing turn it on and off; the text box fallback editor does not do it. The Book tool (Book tools → Typesetting → Smart punctuation) uses the same rules and the book's language, and covers table cells. See spec/features/typesetting/smart-punctuation.md.
- **Undo while typing.** Undo takes back one stretch of typing at a time, not the whole editing session. The words typed so far are kept as an undo step after a pause of a second in the typing, before and after a paste or a cut, before and after a correction from the spelling menu, and before anything else changes the book (a style, a move, an undo or redo). The editor stays open through all of these. Undo and redo from the ribbon, menu or keyboard shortcut close the editor first, so that what is on the page and what the book holds are the same. Ctrl+Z with the caret in the box is the box's own: it takes back the last typing in the box without touching the book.

## Paragraph details

| Control | Values |
|---|---|
| Line spacing | 1.0 · 1.15 · 1.3 · 1.5 · 1.8 · 2.0 (multiplier of size) |
| Space before / Space after | 0 · 4 · 8 · 12 · 18 · 24 pt, or "The style's" to take the paragraph's own value away. The two add together, and space before is left off at the top of a column. Exact values are in the Properties panel's **Paragraph** section |
| Indent / outdent | ±0.25 in (18 pt) of left indent for each press |
| First-line indent | toggles 1.2 em of the type size (a paragraph that sets 0 has none, whatever its style says) |
| Lists | Bullet `•` or `1.` numbering with a 1.3 em hanging marker. Numbering counts non-empty paragraphs |
| Drop cap | First letter floats at 2.15 × line height, weight 600, warm ink |
| Letter spacing (Expert) | Tight −0.02 · Normal · Loose 0.03 · Very loose 0.08 em |
| OpenType (Design panel) | liga · onum · smcp · swsh · frac → `font-feature-settings` |

**Each paragraph has its own look (D-58).** Alignment, space before, space after, line spacing, first-line indent, indent and right indent are set for a paragraph, not a frame, over what its style says; a paragraph that sets nothing takes its style's values, and a frame's other paragraphs are not touched. The Paragraph group's controls and the Properties panel's Paragraph section change the paragraphs under the caret or selection of the open editor, and every paragraph of the selected frame (the paragraphs a frame of a story shows) when no editor is open, in Easy and in Expert alike. Pressing Enter gives the new paragraph the look of the one it split; joining paragraphs keeps the first one's look; typing in a paragraph leaves the rest as they were. Bullets, numbers, the drop cap and letter spacing are listed but not built yet.

## Fonts

The picker offers the bundled families (Literata, Source Serif 4, Atkinson Hyperlegible, Inter) plus "From style" and system fonts. Preflight warns when a font forbids embedding (05).

## Find & replace and spelling

- **Find & replace** (D-62; Ctrl+F, Ctrl+H, Home → Editing → Find & replace, Edit → Find… and Replace…): a bar above the page with Find, Replace with, previous and next, a count ("3 of 12", announced as it changes), **Replace** and **Replace all** (one undo step; the bar says how many were replaced and how many were left alone in locked frames or on other master pages). It searches every story, text frame, shape, table cell and master page in Rust, in reading order (by spread, page, then top to bottom), and next and previous open the spread and select the words in the on-page editor while every match is marked on the page. Expert adds match case, whole word and a regular expression (the Rust `regex` syntax, linear time; `$1` in the replacement is a group). The replacement takes the look of the words it replaces and is not run through smart punctuation. An agent has the same through `find_text` and `replace_text`. See spec/features/proofing/find-and-replace.md.
- **Spelling** (D-25): wavy underlines under misspelt words, while typing and on the page (text frames, flowing text, the words in shapes and the cells of tables), from Folio's own checker rather than the webview's or the system's, so the language is the same on Linux and Windows and Rust-owned text can be checked too. It is on by default, and the Home tab's Spelling button and Preferences turn it off. The language is the book's (en-CA unless the book says otherwise), and a run can carry its own `lang`. Right-click a misspelt word for suggestions, Ignore in this book (kept with the book) and Add to dictionary (kept for every book on this computer, in the settings document as `spelling.personal`, and removed again from Preferences → Spelling); Alt+F7 jumps to the next misspelling and Shift+F10 opens the same menu from the keyboard. Words ignored in a book travel with the file (`proofing.ignore`); words added to the dictionary stay with the person's settings. The English (Canada) dictionary is bundled. Preferences → Spelling lists the others (English for the United States, the United Kingdom and Australia, French, Spanish, Brazilian Portuguese and Dutch) with their size and licence, and downloads one when asked, with a tint that fills in behind its row as the bytes arrive (the plugin tells every window how far a download has got, about once for each percent): each file is fetched over HTTPS from a pinned address, checked against its pinned size and SHA-256, read once, and only then put in place with its licence text beside it; a failed or altered download leaves nothing behind. The book's language is set from a Language list in the Properties card and at the top of the Proofing group, which offers every dictionary Folio knows (saying which are not downloaded yet); changing it is one undo step, and the spelling is checked again against the dictionary for the new language. A book is checked with the dictionary made for its language (`fr-CA` takes French), else the one for its main language, else the bundled English for any English; a language with none is not checked. Dictionaries under a GPL-only licence (German, Italian, Swedish) are not offered. Underlines are never the only sign: a live region says how many misspellings a frame has.

## Footnotes, glossary, index

- **Footnote** (Insert → Book parts): inserts a superscript number at the caret, or at the end of the box, and a `footnote`-style frame at the foot of that page. Numbering is per book. EPUB uses `epub:type="footnote"` asides.
- **Glossary term / Index entry** (Expert): select a word while typing. Terms are collected in Structure → Notes, glossary and index. The back-matter pages are generated at export.
