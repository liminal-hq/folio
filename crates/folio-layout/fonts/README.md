# Bundled fonts

The four families Folio ships with, all under the SIL Open Font Licence 1.1 (the licence texts sit beside the files as `OFL-*.txt`). Book text is laid out the same on every machine because these are always available; installed fonts are offered as well (spec 02 → Fonts).

| Family                | Files                                                                     | Source                                                                                                                                   | Used for                                         |
| --------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Literata              | `Literata.ttf`, `Literata-Italic.ttf` (variable: weight and optical size) | [googlefonts/literata](https://github.com/googlefonts/literata), via `google/fonts` `ofl/literata`                                       | Novels and memoirs; the fallback serif           |
| Source Serif 4        | `SourceSerif4.ttf`, `SourceSerif4-Italic.ttf` (variable)                  | [adobe-fonts/source-serif](https://github.com/adobe-fonts/source-serif), via `google/fonts` `ofl/sourceserif4`                           | Textbooks and long reading                       |
| Inter                 | `Inter.ttf` (variable, upright only)                                      | [rsms/inter](https://github.com/rsms/inter), via `google/fonts` `ofl/inter`                                                              | Captions, labels and headings; the fallback sans |
| Atkinson Hyperlegible | `AtkinsonHyperlegible-{Regular,Bold,Italic,BoldItalic}.ttf` (static)      | [googlefonts/atkinson-hyperlegible](https://github.com/googlefonts/atkinson-hyperlegible), via `google/fonts` `ofl/atkinsonhyperlegible` | Picture books and large print                    |

The files were taken from the `google/fonts` repository on 2026-10-14 and are not modified.
