Named styles keep a whole book consistent.

Every text box uses a style — Story text, Heading, Caption, Body. Change a style and every box using it follows. Expert's Design panel lists all the styles, how often each is used, and lets you apply them with a click.

:::note[Tip]
Typesetting checks (Book tools) find boxes that drifted from their style, and fix them in one go.
:::
