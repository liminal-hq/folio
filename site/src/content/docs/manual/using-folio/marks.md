The coloured lines on the page — and how to change them.

| | |
| --- | --- |
| Pink dashed | Bleed. Anything past it is trimmed off. |
| Purple dashed | Safe margins. Keep words inside. |
| Orange columns | The column grid, when it's on. |
| Cyan lines | Smart guides while you drag, and the baseline grid. |
| Orange folds | The spine on a cover. |
| Rose box | The barcode area on the back cover. |

The Marks button above the page turns each one on or off and lets you pick its colour. Marks never print.
