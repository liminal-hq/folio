What each part of the window is for.

| | |
| --- | --- |
| Folio menu | Top left. New, open, save, export, book tools and interface options. The classic menu bar is hidden until you want it (F10). |
| Document tabs | Every open book. Drag one down to give it its own window. |
| Ribbon or toolbar | Home, Insert, Pages, Layout, View, Export — plus Picture, Shape and Table tabs when one is selected. |
| Sidebar | Properties of whatever is selected, and Pages. Expert adds Design, Structure and Book. |
| Page shelf | Cover first, then every spread. Jax sits beside it when he's open. |
| Status bar | Book size and pages, snapping, saved state — and Jax's perch. |

:::note[Tip]
View → Interface lets you pick from eight toolbar layouts and six sidebar layouts.
:::
