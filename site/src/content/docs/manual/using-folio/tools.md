Eight workbenches for finishing touches.

Folio menu → Book tools opens: Book structure (title page, contents, copyright, index), Typesetting checks, Pictures, Proofing (comments, home printing, read-aloud), Publishing helpers (upload checklist, royalties, launch plan), Series and editions, Accessibility, and Picture-book extras.
