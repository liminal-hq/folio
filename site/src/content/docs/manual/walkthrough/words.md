Type straight onto the page and style it like a word processor.

1. Double-click a text box to start typing.
2. Use the Home tab for font, size, bold, italic, colour, alignment, lists and line spacing.
3. A small toolbar floats above the box while you type — the most-used tools, close at hand.
4. Press Esc or click the page when you're done.

_Figure: Typing with the mini toolbar._

:::note[Tip]
In Easy, styling applies to the whole box. In Expert, select a word first to style just that word.
:::
