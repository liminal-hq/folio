**Folio 0.1.1** repairs the AppImage copy of `folio-mcp` that AI agent programs use. When Folio starts from an updated AppImage, it now refreshes an existing kept copy in the background, so the agent receives the matching version without reopening Help > Connect an agent. Nothing is created for people who have not connected an agent.

## Downloads

- **Windows 11** (x64 and ARM64): a setup `.exe` and an `.msi`. They are unsigned, so SmartScreen warns on first run; choose **More info**, then **Run anyway**.
- **Linux** (x86_64 and aarch64): `.deb`, `.rpm` and AppImage. The packages are unsigned. Make the AppImage executable and run it.
- **For AI agents:** `folio-0.1.1.mcpb` is a one-click bundle for Claude Desktop, and the `@liminal-hq/folio-mcp` npm packages are attached as tarballs. The installers carry `folio-mcp` too, for Help > Connect an agent.
- **`SHA256SUMS`** covers every file. Check your download against it.
