**Folio 0.1.0** is the first public release of the local-first book layout app: make a picture book, a novel or a paperback in Easy mode, bring your words in from Word, Google Docs, ODT, Markdown or a paste, and send the result to Amazon KDP, Kindle, Kobo or a print shop.

## Downloads

- **Windows 11** (x64 and ARM64): a setup `.exe` and an `.msi`. They are unsigned, so SmartScreen warns on first run; choose **More info**, then **Run anyway**.
- **Linux** (x86_64 and aarch64): `.deb`, `.rpm` and AppImage. The packages are unsigned. Make the AppImage executable and run it.
- **For AI agents:** `folio-0.1.0.mcpb` is a one-click bundle for Claude Desktop, and the `@liminal-hq/folio-mcp` npm packages are attached as tarballs (they are not on npm yet). The installers carry `folio-mcp` too, for Help > Connect an agent.
- **`SHA256SUMS`** covers every file. Check your download against it.

## What is in it

- **Books of every kind.** Picture books, novels, textbooks, cookbooks and illustrated guides, poetry and memoirs with photos, each from a preset with the right trim size, bleed, grid and styles, and a New book wizard that shows the cover the look would give. Easy mode talks in plain words and hides what you do not need; Expert shows everything, and switching never removes anything.
- **The page.** Text, picture and note boxes, shapes, tables, master pages, ruler guides, page marks, colour, gradient and texture backgrounds, turned frames, section page numbers, and swatches you can manage from a Swatches tab. Text flows through frames and columns, and a story editor edits a flow a paragraph at a time.
- **Words in.** Import Word, OpenDocument, Rich Text, Markdown and plain text, and choose what each style of the imported document becomes.
- **Proofing.** Spelling with a bundled English (Canada) dictionary and downloads for other languages, underlined as you type, and a Check book dialog (preflight) that says how to fix what it finds, including text in a font nobody has and small text in a rich black.
- **Covers that do the maths.** The spine from the page count and the paper, wrap and bleed for the paperback cover, words on the back cover, and a barcode.
- **Out.** KDP interior and paperback cover PDFs, a print-shop PDF (PDF/X-4), a share PDF, a soft proof for a press's CMYK profile, a cover picture for a store, reflowable EPUBs for Kindle and Kobo, and fixed-layout EPUBs for picture books. After an export, **Where do these go?** says where to upload each file.
- **Yours to keep.** A `.folio` file is an open zip of JSON, Markdown and your pictures. Nothing leaves your computer unless you export it, there is no account, and Folio keeps a recovery copy while you work.
- **Agents.** `folio-mcp` lets an AI agent work on the books you have open, and you can undo what it does.
- **Updates, only when you ask.** Folio looks for a newer version from Help > Check for updates, or at start if you turn that on in Preferences > Updates. It is off until you do.

## Known limits

- The installers and packages are not signed by a publisher, so Windows warns on first run. The updater does check the signature of every update.
- Windows on ARM is built and checked in CI but has not been run on ARM hardware. There is no macOS build.
- Fixed-layout EPUBs are checked on a Kobo Aura, and Amazon's converter (Kindle Previewer) accepts them, but they have not been looked at on a Kindle.
- Updating has not been tried end to end on a real install; the first chance is 0.1.1. An AppImage keeps a copy of `folio-mcp` for agent programs and refreshes it only when Connect an agent is opened.
- From this release a change to the book file format comes with a migration, but the format is young. Keep a copy of anything that matters.
